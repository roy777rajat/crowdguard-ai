# Gallery

Put the `.mp4` files you want to use as camera feeds in this folder. They show up in the video dropdown of each camera on
the Camera wall (the list refreshes about every 10 seconds, no restart needed).

- Only plain `.mp4` names are served: letters, numbers, spaces, `_`, `-`, `.`; the name must start with a letter or number.
- Keep files small (a few MB); the browser loads the whole file.
- Use footage you have the right to use. Videos are not committed to Git (see `.gitignore`).
- Change the folder with `CROWDGUARD_GALLERY` in `.env`.
